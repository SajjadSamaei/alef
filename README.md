# 🏗️ Chehall.com - Construction Company Website

## 📌 About the Project

This is the official website for **Chegall**, designed to showcase our projects, highlight investment opportunities, and provide an interactive experience for users. The website includes a **unit selector feature** for the **Jaroun Project**, allowing users to explore available apartments with detailed specifications.

## 🚀 Features

- **Project Showcase:** A dedicated section for ongoing and completed construction projects.
- **Unit Selector (Jaroun Project):** Interactive tool to select and view apartment details.
- **Investment Information:** Dedicated section for potential investors.
- **Construction Process:** A step-by-step guide for clients to understand our workflow.
- **Responsive Design:** Optimized for both desktop and mobile devices.

## 🛠️ Technologies Used

- **Frontend:** Next.js (React Framework), Tailwind CSS
- **Backend:** Supabase (PostgreSQL, Authentication, API)
- **State Management:** React Context
- **Hosting:** Liara
